## 2. Redis 数据结构设计

### 2.1 Key 总览

| Key Pattern | 类型 | 用途 | TTL |
|------------|:---:|------|:---:|
| `session:{openid}` | Hash | 用户会话信息 | 登录后 7 天 |
| `token:{token}` | String | JWT Token → openid 映射 | Token有效期 |
| `online:{openid}` | String | 在线状态（1=在线）| 60s（心跳刷新） |
| `room:{roomId}` | Hash | 房间运行时状态 | 房间不活跃30min |
| `room:players:{roomId}` | Set | 房间内玩家 openid 集合 | 同房间 |
| `match:queue:{difficulty}` | Sorted Set | 匹配队列（score=ELO）| — |
| `match:wait:{openid}` | String | 匹配开始时间戳 | **用于超时判定** |
| `config:active:{tableName}` | String | 当前生效配置版本号 | — |
| `config:gray:rooms` | Set | 灰度配置房间ID集合 | 灰度结束 |
| `config:data:{tableName}:{version}` | String(JSON) | 配置表数据缓存 | 24h |
| `dashboard:{metric}:{date}` | String | 看板预计算指标 | 5min |
| `dashboard:{metric}:{dateRange}` | String | 长期聚合缓存 | 1h |
| `cache:user:{openid}` | String(JSON) | 用户数据缓存 | 30min |
| `rate:login:{openid}` | String | 登录频率限制 | **1min滑动窗口** |
| `rate:api:{ip}` | String | API请求频率 | **1min滑动窗口** |
| `ban:ip:{ip}` | String | IP封禁标记 | 同封禁时长 |
| `alert:last:gold_anomaly` | String | 金币异常告警去重 | 5min |
| `alert:last:dice_anomaly` | String | 骰子异常告警去重 | 5min |
| `sync:queue:{openid}` | List | 离线同步队列 | 重连后消费 |

## 3. 索引策略

### 3.1 MongoDB 索引

| 集合 | 索引 | 类型 | 说明 |
|------|------|:---:|------|
| `users` | `openid` | unique | 微信登录查询 |
| `users` | `nickName` | text | 后台搜索 |
| `users` | `createdAt_-1` | normal | 用户列表排序 |
| `users` | `banInfo.isBanned_1, banInfo.endTime_1` | compound | 封禁状态查询 |
| `match_records` | `roomId` | unique | 对局记录 |
| `match_records` | `players.openid_1, startedAt_-1` | compound | 用户对局历史 |
| `match_records` | `startedAt_-1` | normal + TTL(90d) | 自动清理 |
| `admin_operation_logs` | `operatorId_1, operatedAt_-1` | compound | 操作日志 |
| `admin_operation_logs` | `operatedAt_-1, operationType_1` | compound | 按类型+时间查询 |
| `config_versions` | `tableName_1, version_-1` | compound | 配置版本 |
| `config_versions` | `status_1` | normal | 审批队列 |
| `tickets` | `submitterOpenid_1, createdAt_-1` | compound | 用户工单 |
| `tickets` | `status_1, priority_1` | compound | 工单处理 |
| `leaderboard_snapshots` | `dimension_1, calculatedAt_-1` | compound + TTL(30d) | 排行榜 |

### 3.2 索引优化建议

- **`match_records.players.openid`**：建议使用多键索引，因为玩家在数组中。如果玩家数量固定（2-4人），可考虑额外冗余 `players_openids` 数组字段用于索引。
- **配置表大JSON**：使用 GridFS 存储超大配置快照（>16MB），普通大小的存于文档内即可。
- **用户标签**：`tags` 字段不建索引，通过应用层过滤。

## 4. 数据安全与备份

### 4.1 备份策略

| 备份类型 | 频率 | 工具 | 保留 |
|---------|:---:|------|:---:|
| MongoDB 全量备份 | 每日 3:00 AM | `mongodump` | 30 天 |
| MongoDB 增量备份 | 每 6 小时 | Oplog | 30 天 |
| Redis RDB | 每 1 小时 | BGSAVE | 7 天 |
| 配置表快照 | 每次发布 | Git + OSS | 永久 |

### 4.2 敏感数据保护

- `openid`：后台搜索列表仅展示后4位（****1234）
- 管理密码：bcrypt + salt 12轮
- 用户IP：日志保留7天，过期自动删除
- 操作日志：不可删除/修改（append-only）

## 5. 数据迁移方案

### 5.1 新用户注册

```
微信授权 → 获取 openid → 查询 users 集合
    ├── 存在 → 加载已有数据 → 更新 lastLoginAt
    └── 不存在 → 创建新文档（默认值）→ 初始化
```

### 5.2 大版本升级

```javascript
/**
 * 数据迁移脚本（v1.x → v2.0）
 */
async function migrate_v1_to_v2() {
    const users = db.users.find({ "talent": { $exists: true } });
    
    for (const user of users) {
        const updates = {};
        
        // 例：新版天赋树结构变更
        if (user.talent.unlocked && typeof user.talent.unlocked === 'object') {
            const newTalent = {};
            for (const [id, level] of Object.entries(user.talent.unlocked)) {
                newTalent[id] = { level, unlockedAt: user.talent.lastModifiedAt };
            }
            updates['talent.unlockedV2'] = newTalent;
        }
        
        // 新增默认字段
        if (!user.settings.fontScale) updates['settings.fontScale'] = 'normal';
        if (!user.settings.hapticLevel) updates['settings.hapticLevel'] = 'full';
        
        if (Object.keys(updates).length > 0) {
            db.users.updateOne({ _id: user._id }, { $set: updates });
        }
    }
}
```
