## 1. 骰子系统

> 📌 核心肉鸽循环：每波结束后每个玩家独立掷骰 → 从对应合并池中抽取3个效果

### 1.1 骰子四池结构

```
骰子 1-3 点（50%概率，对自己有利）
├── 己方增益池（10个） → 合并池
└── 敌方减益池（7个）  → 共17个中抽3个

骰子 4-6 点（50%概率，对玩家不利）
├── 怪物增益池（7个）  → 合并池
└── 队友减益池（7个）  → 共14个中抽3个
```

### 1.4 骰子系统实现

```javascript
const DICE_DRAW_COUNT = 3; // 每次抽取3个

class DiceSystem {
    constructor() {
        /** @type {BuffConfig[]} */
        this.playerBuffPool = [...PLAYER_BUFF_POOL];
        this.enemyDebuffPool = [...ENEMY_DEBUFF_POOL];
        this.monsterBuffPool = [...MONSTER_BUFF_POOL];
        this.teammateDebuffPool = [...TEAMMATE_DEBUFF_POOL];
    }

    /**
     * 服务端掷骰（客户端仅做动画表现）
     * 骰子结果由服务端真随机生成 → 通过 wave_end 消息下发
     * 
     * 此方法在客户端用于本地模拟/单机模式，联机时不调用
     * @param {SeededRandom} rng
     * @returns {{ diceValue: number, pool: string, buffs: BuffConfig[] }}
     */
    roll(rng) {
        const diceValue = rng.nextIntInclusive(1, 6);

        if (diceValue <= 3) {
            // 己方增益(10) + 敌方减益(7) = 17个中抽3个
            const mergedPool = [...this.playerBuffPool, ...this.enemyDebuffPool];
            return {
                diceValue,
                pool: 'PLAYER_FAVOR',
                buffs: this._randomPickN(mergedPool, DICE_DRAW_COUNT, rng),
            };
        } else {
            // 怪物增益(7) + 队友减益(7) = 14个中抽3个
            const mergedPool = [...this.monsterBuffPool, ...this.teammateDebuffPool];
            return {
                diceValue,
                pool: 'MONSTER_FAVOR',
                buffs: this._randomPickN(mergedPool, DICE_DRAW_COUNT, rng),
            };
        }
    }

    /**
     * 从池中不重复抽取 N 个
     * @param {BuffConfig[]} pool
     * @param {number} n
     * @param {SeededRandom} rng
     * @returns {BuffConfig[]}
     */
    _randomPickN(pool, n, rng) {
        const result = [];
        const available = [...pool];
        const drawCount = Math.min(n, available.length);

        for (let i = 0; i < drawCount; i++) {
            const index = rng.nextInt(0, available.length);
            result.push(available[index]);
            available.splice(index, 1);
        }
        return result;
    }
}
```

### 1.5 公平性保障

| 维度 | 方案 |
|------|------|
| 随机源 | 服务端使用 `crypto.randomInt()` 真随机 |
| 客户端角色 | 仅做动画表现，不做任何逻辑决策 |
| 天赋影响 | 天赋「好运」分支修改概率在服务端计算 |
| 日志审计 | 每局所有掷骰结果记录日志，支持玩家申诉 |
| 风控告警 | 连续5次同一数值触发风控 |

### 1.6 骰子动画速度模式

| 模式 | 说明 | 设置 |
|------|------|:---:|
| 普通模式 | 完整动画（掷出→滚动→结果逐一揭示，约2秒） | 默认 |
| 快速模式 | 动画缩短至0.5秒 | 设置页开启 |
| 跳过动画 | 直接弹出结果，无滚动动画 | 设置页开启（提示「可能降低沉浸感」） |

### 1.7 队友减益目标分配规则 `🆕`

> 📌 来自第四轮 Q1：确认队友减益的命中机制。

每次掷骰抽到队友减益效果时，各效果独立选择目标：

```javascript
/**
 * 队友减益目标分配（服务端执行）
 * 
 * 规则：
 * - 每个减益效果独立随机选1名队友（可能命中不同队友，也可能全砸同一人）
 * - 不会命中掷骰者自己（自伤隔离）
 * - 单机模式或仅剩1人在线时，队友减益直接不生效
 * - 可通过天赋「免疫」减少被命中的概率
 * 
 * @param {string} sourcePlayerId - 掷骰者ID
 * @param {BuffConfig[]} buffs    - 抽到的3个效果列表
 * @param {Player[]} allPlayers   - 所有队友（不含自己）
 * @returns {{ targetPlayerId: string, buff: BuffConfig }[]}
 */
function allocateTeammateDebuffs(sourcePlayerId, buffs, allPlayers) {
    const eligiblePlayers = allPlayers.filter(p =>
        p.id !== sourcePlayerId && !p.isAI
    );

    // 没有队友（单机/仅剩1人）→ 所有队友减益不生效
    if (eligiblePlayers.length === 0) return [];

    const results = [];
    for (const buff of buffs) {
        if (buff.poolType !== BuffPoolType.TEAMMATE_DEBUFF) continue;

        // 天赋免疫检查
        const immunityChance = _getTeammateImmunityChance(sourcePlayerId);

        // 每个队友减益效果独立随机选择目标
        const targetIdx = crypto.randomInt(0, eligiblePlayers.length);
        const target = eligiblePlayers[targetIdx];

        // 检查目标是否免疫（天赋/遗物）
        if (Math.random() < immunityChance) {
            // 免疫成功，不生效
            continue;
        }

        results.push({ targetPlayerId: target.id, buff: { ...buff } });
    }

    return results;
}
```

**关键设计决策**：

| 规则 | 说明 | 需求来源 |
|------|------|---------|
| 独立随机 | 每次掷骰的3个减益各独立随机选择目标，可能全砸同一人 |需求 §5.3.4 |
| 自伤隔离 | 不会命中掷骰者自己 |需求 §5.3.4 |
| 单机不生效 | 单人或仅剩1人在线时队友减益直接不生效 |需求 §5.3.4 |
| 免疫机制 | 天赋「免疫」+10%/20%/30%，「不朽水晶」SSR-04 免疫率+20% |需求 §5.1 |

### 2.2 成长系统实现

```javascript
class TowerGrowthSystem {
    /**
     * 对场上所有塔应用成长
     * @param {Tower[]} towers
     * @param {number} currentWave
     * @param {number} multiplayerSlowdown - 多人成长降速系数（2人1.0, 3人0.9, 4人0.8）
     * @returns {{ towerId: string, growths: {stat: string, value: number}[] }[]}
     */
    applyGrowth(towers, currentWave, multiplayerSlowdown) {
        multiplayerSlowdown = multiplayerSlowdown || 1.0;
        /** @type {{ towerId: string, growths: object[] }[]} */
        const results = [];

        for (const tower of towers) {
            const config = TOWER_GROWTH_CONFIGS[tower.type];
            if (!config) continue;

            /** @type {{ stat: string, value: number }[]} */
            const appliedGrowths = [];

            // 每波基础成长（受多人系数影响）
            for (const growth of config.perWaveGrowth) {
                const actualValue = growth.value * multiplayerSlowdown;
                this._applyStatGrowth(tower, growth.stat, actualValue);
                tower.accumulatedGrowth[growth.stat] =
                    (tower.accumulatedGrowth[growth.stat] || 0) + actualValue;
                appliedGrowths.push({ stat: growth.stat, value: actualValue });
            }

            // 每N波额外成长
            for (const nWave of config.perNWaveGrowth) {
                if (currentWave % nWave.everyNWaves === 0) {
                    for (const growth of nWave.growths) {
                        const actualValue = growth.value * multiplayerSlowdown;
                        this._applyStatGrowth(tower, growth.stat, actualValue);
                        tower.accumulatedGrowth[growth.stat] =
                            (tower.accumulatedGrowth[growth.stat] || 0) + actualValue;
                        appliedGrowths.push({ stat: growth.stat, value: actualValue });
                    }
                }
            }

            if (appliedGrowths.length > 0) {
                results.push({ towerId: tower.id, growths: appliedGrowths });
            }
        }

        return results;
    }

    /**
     * 应用单个属性成长到塔
     * @param {Tower} tower
     * @param {string} stat
     * @param {number} value
     */
    _applyStatGrowth(tower, stat, value) {
        switch (stat) {
            case 'attack':
                tower.baseAttack = tower.baseAttack.add(FixedPoint.fromFloat(value));
                break;
            case 'attackSpeed':
                // value为-50表示攻速间隔-50ms
                tower.baseAttackSpeed += value / 1000;
                tower.baseAttackSpeed = Math.max(0.2, tower.baseAttackSpeed);
                break;
            case 'slowPercent':
                tower.slowPercent += value; // 冰塔减速%
                tower.slowPercent = Math.min(90, tower.slowPercent);
                break;
            case 'slowDuration':
                tower.slowDuration = (tower.slowDuration || 2) + value; // 冰塔减速时长
                break;
            case 'pierceCount':
                tower.pierceCount = (tower.pierceCount || 3) + value; // 魔法塔穿透数
                break;
            case 'dotDamage':
                tower.dotDamage = (tower.dotDamage || 4) + value; // 毒塔DOT
                break;
            case 'maxStacks':
                tower.maxStacks = (tower.maxStacks || 5) + value; // 毒塔最大层数
                break;
            case 'chainCount':
                tower.chainCount = (tower.chainCount || 3) + value; // 电塔连锁数
                break;
            case 'splashRange':
                tower.splashRange = (tower.splashRange || 1) + value; // 炮塔溅射范围
                break;
            case 'auraAttackBonus':
                tower.auraAttackBonus = (tower.auraAttackBonus || 15) + value; // 图腾塔光环
                break;
            case 'auraRange':
                tower.auraRange = (tower.auraRange || 2) + value; // 图腾塔范围
                break;
            case 'minionHP':
                tower.minionHP = (tower.minionHP || 50) + value; // 召唤小兵HP
                break;
            case 'minionATK':
```

### 2.4 塔属性成长上限 `🆕`

> 📌 来自第四轮 §16.2：防止无限成长导致数值膨胀。

不同于之前设计的衰减系数，新需求明确定义了**第20波期望攻击**和**成长上限**（基础值倍数）。超过上限后该属性不再成长（其他属性继续成长）。

```javascript

 * 塔属性成长上限配置
 * 超过上限后，对应属性的每波成长不再应用
 */
const TOWER_GROWTH_CAPS = Object.freeze({
    arrow:   { stat: 'attack',       baseValue: 25, capMultiplier: 3.5 },  // 攻≤87.5
    cannon:  { stat: 'attack',       baseValue: 40, capMultiplier: 3.5 },  // 攻≤140
    ice:     { stat: 'slowPercent',  baseValue: 30, capValue: 80 },        // 减速≤80%
    magic:   { stat: 'pierceCount',  baseValue: 3,  capValue: 12 },        // 穿透≤12
    poison:  { stat: 'dotMaxStacks', baseValue: 5,  capValue: 15 },        // 层数≤15
    tesla:   { stat: 'chainCount',   baseValue: 3,  capValue: 12 },        // 连锁≤12
    totem:   { stat: 'auraAttackBonus', baseValue: 15, capValue: 40 },     // 光环≤40%
    summon:  { stat: 'minionHP',     baseValue: 50, capValue: 250 },       // 小兵HP≤250
});

/**
 * 检查塔属性是否已达成长上限
 * @param {Tower} tower
 * @param {string} stat
 * @param {number} addValue
 * @returns {boolean} true=已达上限不再成长
 */
function isGrowthCapped(tower, stat, addValue) {
    const cap = TOWER_GROWTH_CAPS[tower.type];
    if (!cap || cap.stat !== stat) return false;

    const currentValue = tower.accumulatedGrowth[stat] || 0;
    let maxGrowth;
    if (cap.capMultiplier) {
        maxGrowth = cap.baseValue * (cap.capMultiplier - 1); // 上限=基础值×(倍数-1)
    } else if (cap.capValue) {
        maxGrowth = cap.capValue - cap.baseValue;
    }
    return currentValue >= (maxGrowth || Infinity);
}
```

### 3.3 抽卡实现

```javascript
class GachaSystem {
    constructor() {
        /** @type {Map<string, PityCounter>} */
        this.pityCounters = new Map();
    }

    /**
     * 服务端抽卡（客户端仅接收结果做动画）
     * @param {string} playerId
     * @param {SeededRandom} rng - 服务端真随机
     * @returns {{ rarity: string, item: GachaItem, isPity: boolean }}
     */
    draw(playerId, rng) {
        const pity = this._getOrCreatePity(playerId);

        // 检查保底优先
        /** @type {string|null} */
        let rarity = null;
        let isPity = false;

        if (pity.drawsSinceLastSSR >= GACHA_RATES.SSR.pityAfter) {
            rarity = GachaRarity.SSR;
            isPity = true;
        } else if (pity.drawsSinceLastSR >= GACHA_RATES.SR.pityAfter) {
            rarity = GachaRarity.SR;
            isPity = true;
        }

        // 非保底则按概率
        if (!rarity) {
            rarity = this._rollRarity(rng);
        }

        const pool = GACHA_POOL[rarity];
        const item = pool[rng.nextInt(0, pool.length)];

        this._updatePity(pity, rarity);

        return { rarity, item, isPity };
    }

    /**
     * 按概率抽取稀有度
     * @param {SeededRandom} rng
     * @returns {string}
     */
    _rollRarity(rng) {
        const roll = rng.next();
        let cumulative = 0;
        for (const rarity of [GachaRarity.N, GachaRarity.R, GachaRarity.SR, GachaRarity.SSR]) {
            cumulative += GACHA_RATES[rarity].rate;
            if (roll < cumulative) return rarity;
        }
        return GachaRarity.N;
    }

    /**
     * @param {string} playerId
     * @returns {PityCounter}
     */
    _getOrCreatePity(playerId) {
        if (!this.pityCounters.has(playerId)) {
            this.pityCounters.set(playerId, {
                totalDraws: 0,
                drawsSinceLastSR: 0,
                drawsSinceLastSSR: 0,
            });
        }
        return this.pityCounters.get(playerId);
    }

    /**
     * 更新保底计数器
     * @param {PityCounter} pity
     * @param {string} drawn
     */
    _updatePity(pity, drawn) {
        pity.totalDraws++;
        pity.drawsSinceLastSR++;
        pity.drawsSinceLastSSR++;

        if (drawn === GachaRarity.SR || drawn === GachaRarity.SSR) {
            pity.drawsSinceLastSR = 0;
        }
        if (drawn === GachaRarity.SSR) {
            pity.drawsSinceLastSSR = 0;
        }
    }
}

/**
 * @typedef {object} PityCounter
 * @property {number} totalDraws
 * @property {number} drawsSinceLastSR
 * @property {number} drawsSinceLastSSR
 */
```

## 4. Buff/Debuff 运行时管理

```javascript
class BuffInstance {
    /**
     * @param {BuffConfig} config
     * @param {number} remainingWaves - -1=永久, 0=即时, N=N波
     * @param {number} [appliedFrame=0]
     */
    constructor(config, remainingWaves, appliedFrame) {
        this.config = config;
        this.remainingWaves = remainingWaves;
        this.appliedFrame = appliedFrame || 0;
    }

    /** @returns {boolean} */
    isExpired() {
        if (this.remainingWaves === -1) return false; // 永久
        return this.remainingWaves <= 0;
    }

    /** 波次结束时调用 */
    onWaveEnd() {
        if (this.remainingWaves > 0) this.remainingWaves--;
    }
}

class BuffManager {
    constructor() {
        /** @type {Map<string, BuffInstance[]>} playerBuffs */
        this.playerBuffs = new Map();
        /** @type {BuffInstance[]} */
        this.globalBuffs = [];
    }

    /**
     * 为玩家添加Buff
     * @param {string} playerId
     * @param {BuffConfig} config
     * @param {number} waves
     */
    addPlayerBuff(playerId, config, waves) {
        if (!this.playerBuffs.has(playerId)) {
            this.playerBuffs.set(playerId, []);
        }
        this.playerBuffs.get(playerId).push(new BuffInstance(config, waves));
    }

    /**
     * 添加全局Buff（怪物增益等）
     * @param {BuffConfig} config
     * @param {number} waves
     */
    addGlobalBuff(config, waves) {
        this.globalBuffs.push(new BuffInstance(config, waves));
    }

    /**
     * 波次结束时清理过期Buff
     */
    onWaveEnd() {
        for (const buffs of this.playerBuffs.values()) {
            for (const b of buffs) b.onWaveEnd();
            // 移除过期
            const active = buffs.filter(b => !b.isExpired());
            this.playerBuffs.set(buffs === active ? null : null, active);
        }
        for (const b of this.globalBuffs) b.onWaveEnd();
        this.globalBuffs = this.globalBuffs.filter(b => !b.isExpired());
    }

    /**
     * 获取玩家的所有活跃Buff
     * @param {string} playerId
     * @returns {BuffInstance[]}
     */
    getPlayerBuffs(playerId) {
        return (this.playerBuffs.get(playerId) || []).filter(b => !b.isExpired());
    }
}
```

```javascript
    /**
     * 生成商店
     * @param {number} waveNumber
     * @param {string} playerId
     * @param {SeededRandom} rng - 派生自 room_seed + "shop" + wave
     * @returns {ShopState}
     */
    generateShop(waveNumber, playerId, rng) {
        const shopType = this._getShopType(waveNumber);
        const discount = shopType === 'BOSS_PREP' ? 0.8 : 1.0;

        /** @type {ShopItem[]} */
        const items = [];
        const itemCount = { 3: 3, 7: 4, 12: 5, 17: 5 }[waveNumber] || 3;

        // 从商品池随机抽取
        const pool = this._getItemPool(waveNumber);
        const picked = rng.pickN(pool, itemCount);

        for (const template of picked) {
            const price = Math.round(
                (template.basePrice + (rng.next() - 0.5) * template.basePrice * 0.4) * discount
            );
            items.push({
                id: 'shop_' + Date.now().toString(36),
                type: template.type,
                name: template.name,
                description: template.description,
                price,
                originalPrice: template.basePrice,
                sold: false,
            });
        }

        return { waveNumber, shopType, items, discount, refreshCount: 0, maxRefresh: 2 };
    }

    /**
     * 购买商品
     * @returns {{ success: boolean, error?: string }}
     */
    buyItem(playerId, shop, itemId) {
        const item = shop.items.find(i => i.id === itemId);
        if (!item) return { success: false, error: '商品不存在' };
        if (item.sold) return { success: false, error: '已售罄' };

        const player = GameWorld.instance.getPlayer(playerId);
        if (player.gold < item.price) return { success: false, error: '金币不足' };

        player.gold -= item.price;
        item.sold = true;

        // 发放商品
        this._grantItem(playerId, item);

        return { success: true };
    }

    /** @param {number} wave @returns {string} */
    _getShopType(wave) {
        if (wave === 17) return 'BOSS_PREP';
        if (wave === 12) return 'ADVANCED';
        if (wave === 7) return 'INTERMEDIATE';
        return 'BASIC';
```

```javascript
    tryTrigger(waveNumber, rng) {
```

## 9. 多路线分支系统

```javascript
class RouteBranchSystem {
    constructor() {
        this.routes = [
            { id: 'SAFE',   name: '安全路线',  monsterStatMul: 0.9, goldMul: 0.8,  extraDraws: 0 },
            { id: 'NORMAL', name: '普通路线',  monsterStatMul: 1.0, goldMul: 1.0,  extraDraws: 0 },
            { id: 'RISKY',  name: '高风险路线', monsterStatMul: 1.3, goldMul: 1.5,  extraDraws: 1 },
        ];
        this.currentRoute = 'NORMAL'; // 默认
    }

    /**
     * 选择路线（联机由房主选择，单机由玩家自选）
     * @param {string} routeId
     * @returns {boolean}
     */
    selectRoute(routeId) {
        if (!this.routes.find(r => r.id === routeId)) return false;
        this.currentRoute = routeId;
        return true;
    }

    /** @returns {object} */
    getCurrentRoute() {
        return this.routes.find(r => r.id === this.currentRoute);
    }
}
```

触发波次：第7波、第14波后。联机由房主选择，全队统一。
